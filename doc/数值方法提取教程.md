## 功能概述

### 这个功能是做什么的？

这个新功能可以从科学文献中**自动提取数值方法和约束条件**，并生成结构化的YAML文件。具体包括：

✅ **自动检索文献**：根据关键词从Google Scholar等数据库搜索相关论文  
✅ **提取方法学章节**：自动定位"Numerical Method"、"Model Setup"等章节  
✅ **提取LaTeX方程**：识别并保存数学方程  
✅ **提取变量定义**：包括变量符号、含义和单位  
✅ **提取边界条件**：空间和时间边界条件  
✅ **提取离散格式**：有限差分、有限元等数值方法  
✅ **结构化输出**：生成易于阅读和处理的YAML文件  

### 适用场景

- 📚 文献调研：快速了解某领域常用的数值方法
- 🔬 模型复现：收集复现论文模型所需的约束条件
- 📊 对比分析：比较不同研究使用的方法和参数
- 📝 综述撰写：整理某主题的常用数值方法

## 使用方法

### 方法1：完整工作流（检索+提取）

这种方法会先搜索文献，然后从下载的文本中提取约束条件。

```bash
python MethodExtraction/IntegratedWorkflow.py \
    --keyword "computational fluid dynamics" \
    --api YOUR_SERPAPI_KEY \
    --year 2020 2024 \
    --max 10 \
    --output ./output_constraints
```

**参数说明：**
- `--keyword` 或 `-k`: 搜索关键词（必需）
- `--api` 或 `-a`: SerpAPI密钥，可以提供多个（必需）
- `--year` 或 `-y`: 年份范围，格式为 `起始年 结束年`（默认：2020 2024）
- `--max` 或 `-m`: 最大提取文献数（默认：10）
- `--output` 或 `-o`: 输出目录（默认：./constraints_output）

**示例：**

```bash
# 搜索机器学习相关文献
python MethodExtraction/IntegratedWorkflow.py \
    -k "machine learning chemistry" \
    -a YOUR_API_KEY \
    -y 2022 2024 \
    -m 5

# 搜索计算流体力学文献
python MethodExtraction/IntegratedWorkflow.py \
    -k "CFD turbulence" \
    -a API_KEY_1 API_KEY_2 \
    -y 2020 2023
```

### 方法2：仅提取约束条件（已有文本文件）

如果你已经有PDF转换后的文本文件，可以直接提取约束条件：

```bash
python MethodExtraction/ExtractConstraints.py \
    --batch \
    --input ./RawFromPDF \
    --output ./constraints_output \
    --keyword "CFD" \
    --max 10
```

**参数说明：**
- `--batch` 或 `-b`: 批量处理模式
- `--input` 或 `-i`: 输入文件夹（包含.txt文件）
- `--output` 或 `-o`: 输出文件夹
- `--keyword` 或 `-k`: 关键词（用于文件命名）
- `--max` 或 `-m`: 最大处理文件数

**单个文件提取：**

```bash
python MethodExtraction/ExtractConstraints.py \
    --input ./paper.txt \
    --output ./constraints.yaml
```

### 方法3：在Python代码中使用

```python

```

## 输出格式说明

### YAML文件结构

生成的`Constraints.yaml`文件包含以下结构：

```yaml
metadata:
  title: 论文标题或DOI
  doi: 10.xxxx/xxxxx

governing_equations:
  - equation: \frac{\partial u}{\partial t} + u \frac{\partial u}{\partial x} = \nu \frac{\partial^2 u}{\partial x^2}
    description: Navier-Stokes方程

variables:
  - symbol: u
    description: velocity
    unit: m/s
  - symbol: t
    description: time
    unit: s
  - symbol: ν
    description: kinematic viscosity
    unit: m²/s

boundary_conditions:
  spatial:
    - "At the inlet: u = U_0"
    - "At the wall: u = 0 (no-slip condition)"
  temporal:
    - 待定

initial_conditions:
  - 待定

discretization:
  spatial_scheme:
    - finite difference method
    - upwind scheme
  temporal_scheme:
    - 待定
  grid_type: 待定
  time_step: 待定

solver_settings:
  convergence_criteria: 待定
  max_iterations: 待定
  relaxation_factors: 待定
```

### 字段说明

#### 1. metadata（元数据）
- `title`: 论文标题或标识
- `doi`: 数字对象标识符

#### 2. governing_equations（控制方程）
- `equation`: LaTeX格式的方程
- `description`: 方程描述

#### 3. variables（变量）
- `symbol`: 变量符号（如 u, T, p）
- `description`: 变量含义（如 velocity, temperature）
- `unit`: 单位（如 m/s, K, Pa）

#### 4. boundary_conditions（边界条件）
- `spatial`: 空间边界条件（如入口、出口、壁面）
- `temporal`: 时间边界条件

#### 5. initial_conditions（初始条件）
- 系统在t=0时的状态

#### 6. discretization（离散化）
- `spatial_scheme`: 空间离散格式（如有限差分、有限元）
- `temporal_scheme`: 时间离散格式（如Runge-Kutta、Euler）
- `grid_type`: 网格类型
- `time_step`: 时间步长

#### 7. solver_settings（求解器设置）
- `convergence_criteria`: 收敛标准
- `max_iterations`: 最大迭代次数
- `relaxation_factors`: 松弛因子

### "待定"标记

如果某项信息在论文中未找到或无法提取，系统会标记为**"待定"**。这有助于：
- 快速识别缺失信息
- 后续手动补充
- 评估论文的完整性

### 案例2：对比不同论文的方法

提取多篇论文后，可以编写简单脚本对比：

```python
import yaml
import os

# 读取所有YAML文件
constraints_dir = './turbulence_constraints'
all_schemes = []

for filename in os.listdir(constraints_dir):
    if filename.endswith('.yaml'):
        with open(os.path.join(constraints_dir, filename), 'r') as f:
            data = yaml.safe_load(f)
            schemes = data.get('discretization', {}).get('spatial_scheme', [])
            all_schemes.extend(schemes)

# 统计最常用的方法
from collections import Counter
scheme_counts = Counter(all_schemes)

print("最常用的空间离散格式：")
for scheme, count in scheme_counts.most_common(5):
    print(f"  {scheme}: {count}次")
```

**输出：**
```
最常用的空间离散格式：
  finite volume method: 8次
  upwind scheme: 5次
  central difference: 3次
  finite element method: 2次
```

## 常见问题

### Q1: 为什么有些字段显示"待定"？

**A**: 可能的原因：
1. 论文中确实未提供该信息
2. 信息格式不规范，程序无法识别
3. 信息在其他章节（如补充材料）

**解决方法：**
- 手动查阅原文补充
- 调整提取规则（修改正则表达式）
- 使用LLM增强提取（见下方Q5）

### Q2: 如何处理非英文文献？

**A**: 当前版本主要支持英文文献。对于中文文献：
- 可以先翻译成英文
- 修改关键词匹配规则以支持中文

### Q3: 提取的LaTeX方程格式不正确？

**A**: 常见问题：
- PDF转文本时方程可能损坏
- 建议使用高质量的PDF
- 可以手动修正YAML文件

### Q4: 如何自定义提取规则？

**A**: 编辑`ExtractConstraints.py`中的正则表达式：

```python
# 在 extract_boundary_conditions 函数中添加新关键词
keywords = [
    'boundary condition', 
    'initial condition',
    '你的自定义关键词',  # 添加这里
]
```

### Q5: 能否结合LLM提高准确性？

**A**: 可以！修改代码调用LLM：

```python
def extract_with_llm(text, section):
    """使用LLM提取信息"""
    from Utility.GetResponse import GetClaudeResponse
    
    prompt = f"""
    从以下文本中提取{section}相关信息：
    
    {text}
    
    请以结构化格式返回。
    """
    
    response = GetClaudeResponse(prompt)
    return parse_llm_response(response)
```

### Q6: 批量处理时程序崩溃怎么办？

**A**: 建议：
1. 减少`--max`参数值，分批处理
2. 检查输入文件编码（应为UTF-8）
3. 查看错误日志定位问题文件

### Q7: YAML文件如何转换为其他格式？

**A**: 使用Python转换：

```python
import yaml
import json

# YAML转JSON
with open('constraints.yaml', 'r') as f:
    data = yaml.safe_load(f)
with open('constraints.json', 'w') as f:
    json.dump(data, f, indent=2)

# YAML转Excel
import pandas as pd
df = pd.DataFrame(data['variables'])
df.to_excel('variables.xlsx', index=False)
```

### 3. 构建知识库

将提取的约束条件存入数据库：

```python
import sqlite3
import yaml

conn = sqlite3.connect('constraints.db')
cursor = conn.cursor()

# 创建表
cursor.execute('''
    CREATE TABLE IF NOT EXISTS equations (
        id INTEGER PRIMARY KEY,
        doi TEXT,
        equation TEXT,
        description TEXT
    )
''')

# 插入数据
for yaml_file in yaml_files:
    with open(yaml_file, 'r') as f:
        data = yaml.safe_load(f)
    for eq in data['governing_equations']:
        cursor.execute(
            'INSERT INTO equations (doi, equation, description) VALUES (?, ?, ?)',
            (data['metadata']['doi'], eq['equation'], eq['description'])
        )

conn.commit()
```

## 附录：完整示例脚本

```python
#!/usr/bin/env python3
"""
完整示例：从搜索到分析
"""

import os
from MethodExtraction.IntegratedWorkflow import search_and_extract_constraints
from MethodExtraction.ExtractConstraints import batch_extract_constraints
import yaml

# 1. 搜索并提取
search_and_extract_constraints(
    keyword="computational fluid dynamics",
    api_keys=["YOUR_API_KEY"],
    year_start=2023,
    year_end=2024,
    max_papers=5,
    output_dir="./cfd_constraints"
)

# 2. 分析结果
results = []
for filename in os.listdir('./cfd_constraints'):
    if filename.endswith('.yaml'):
        with open(os.path.join('./cfd_constraints', filename), 'r') as f:
            data = yaml.safe_load(f)
            results.append(data)

# 3. 统计
print(f"共提取 {len(results)} 篇文献")
print(f"共提取 {sum(len(r['governing_equations']) for r in results)} 个方程")

# 4. 导出摘要
with open('summary.txt', 'w') as f:
    for i, result in enumerate(results, 1):
        f.write(f"论文 {i}: {result['metadata']['doi']}\n")
        f.write(f"  方程数: {len(result['governing_equations'])}\n")
        f.write(f"  变量数: {len(result['variables'])}\n")
        f.write("\n")

print("完成！结果保存在 summary.txt")
```
