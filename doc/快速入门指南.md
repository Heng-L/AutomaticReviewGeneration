---

## 🎯 这是什么？

这是一个**自动从学术文献中提取数值方法和约束条件**的工具，专门设计用于：
- 从PDF论文中提取控制方程（LaTeX格式）
- 提取变量定义及其单位
- 提取边界条件和初始条件
- 提取数值离散方法
- 生成结构化的YAML文件

**适合人群**：科研人员、研究生、工程师

## 📝 三种使用方式

### 方式1: 命令行 - 单个文件

```bash

    --input ./my_paper.txt \
    --output ./my_constraints.yaml
```

### 方式2: 命令行 - 批量处理

```bash
python MethodExtraction/ExtractConstraints.py \
    --batch \
    --input ./papers_folder \
    --output ./output_folder \
    --keyword "CFD" \
    --max 10
```

## 🔧 常见使用场景

### 场景1: 文献调研

**需求**：你在研究CFD，想了解最新论文使用的数值方法。

```bash
# 1. 搜索并下载论文（假设已完成）
# 2. 提取约束条件
python MethodExtraction/ExtractConstraints.py \
    -b -i ./downloaded_papers -o ./cfd_methods -k "CFD" -m 20

# 3. 分析结果
python -c "
import yaml, os
from collections import Counter

schemes = []
for f in os.listdir('./cfd_methods'):
    if f.endswith('.yaml'):
        data = yaml.safe_load(open(f'./cfd_methods/{f}'))
        schemes.extend(data['discretization']['spatial_scheme'])

for s, c in Counter(schemes).most_common(5):
    print(f'{c}x: {s}')
"
```

### 场景2: 模型复现

**需求**：你要复现一篇论文的模型，需要整理所有约束条件。

```bash
# 提取单篇论文
python MethodExtraction/ExtractConstraints.py \
    -i ./target_paper.txt \
    -o ./reproduction_constraints.yaml

# 查看结果
cat reproduction_constraints.yaml
```

### 场景3: 综述写作

**需求**：你在写综述，需要对比多篇论文的方法。

```python
# compare_methods.py
import yaml
import os
import pandas as pd

# 读取所有YAML
constraints_list = []
for f in os.listdir('./constraints'):
    if f.endswith('.yaml'):
        with open(f'./constraints/{f}', 'r') as file:
            constraints_list.append(yaml.safe_load(file))

# 创建对比表
comparison = []
for c in constraints_list:
    comparison.append({
        'DOI': c['metadata']['doi'],
        '方程数': len(c['governing_equations']),
        '变量数': len(c['variables']),
        '离散方法': ', '.join(c['discretization']['spatial_scheme'][:2])
    })

df = pd.DataFrame(comparison)
df.to_excel('method_comparison.xlsx', index=False)
print("对比表已生成: method_comparison.xlsx")
```

## 📊 输出YAML格式详解

```yaml
metadata:
  title: 论文标题或标识
  doi: 数字对象标识符

governing_equations:           # 控制方程
  - equation: LaTeX格式的方程
    description: 方程描述或含义

variables:                     # 变量定义
  - symbol: 变量符号（如 u, T, p）
    description: 变量含义
    unit: 单位（如 m/s, K, Pa）

boundary_conditions:           # 边界条件
  spatial:                     # 空间边界
    - "描述文本"
  temporal:                    # 时间边界
    - "描述文本或待定"

initial_conditions:            # 初始条件
  - "描述文本或待定"

discretization:                # 离散化方法
  spatial_scheme:              # 空间离散
    - "方法描述"
  temporal_scheme:             # 时间离散
    - "方法描述或待定"
  grid_type: "网格类型或待定"
  time_step: "时间步长或待定"

solver_settings:               # 求解器设置
  convergence_criteria: "收敛标准或待定"
  max_iterations: "最大迭代次数或待定"
  relaxation_factors: "松弛因子或待定"
```

### "待定"标记的含义

- 表示在论文中**未找到**该信息
- 需要**手动补充**
- 或该信息**不适用**于该研究

## 🐛 故障排除

### 问题1: 提取结果大部分是"待定"

**原因**：
- PDF转文本质量差
- 论文格式不规范
- 关键词匹配规则不适配

**解决**：
1. 使用高质量PDF
2. 手动检查文本文件
3. 自定义提取规则（见高级配置）

### 问题2: LaTeX方程格式错误

**原因**：PDF转文本时方程可能损坏

**解决**：
1. 使用专业PDF提取工具
2. 手动修正YAML文件中的方程

### 问题3: 变量提取不准确

**原因**：变量定义格式多样

**解决**：
1. 增加更多正则表达式模式
2. 使用LLM辅助提取
